# Sales Manager Simulator

Тренажёр для менеджеров по продажам. Выбираешь тип клиента, отвечаешь на его возражения — нейросеть оценивает ответ и даёт обратную связь.

## Что внутри

Четыре типа клиентов: скептик, занятой, экономный, агрессивный. Для каждого — свой пул возражений.

Отвечаешь в свободной форме, получаешь оценку по четырём критериям:

- Эмпатия
- Аргументация
- Работа с возражением
- Тон общения

Плюс разбор: что получилось, что стоит доработать, и конкретный совет.

Оценку даёт LLM через OpenRouter. Если API недоступен — используются локальные заготовки, чтобы тренировка не прерывалась.

## Установка

Нужен Python 3.8+ и API-ключ OpenRouter.

```bash
git clone https://github.com/your-username/sales-simulator.git
cd sales-simulator

python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # Linux/Mac

pip install -r requirements.txt
```

Файл `requirements.txt`:

```
requests>=2.28.0
```

## Настройка

Создай `.env` в корне проекта:

```
OPENROUTER_API_KEY=sk-or-v1-xxxxxxxxxxxxx
LLM_MODEL=stepfun/step-3.5-flash:free
```

Ключ берётся на https://openrouter.ai/keys

Модель можно менять. Для оценки хорошо подходят:

- `stepfun/step-3.5-flash:free` — бесплатная
- `google/gemini-flash-1.5`
- `openai/gpt-3.5-turbo`
- `anthropic/claude-3-haiku`

## Запуск

```bash
python main.py
```

Дальше — меню. Выбираешь тип клиента, получаешь возражение, пишешь ответ.

В режиме тренировки работают две команды:

- `меню` — выход в главное меню
- `далее` — пропустить текущее возражение

Пример работы:

```
ТРЕНИРОВКА С СКЕПТИКОМ

Прогресс: 2/10 (20%)
Совет: Спроси клиента, какие доказательства были бы для него убедительны

Клиент: "Звучит слишком хорошо, чтобы быть правдой"

Твой ответ:
> Понимаю ваши сомнения. Давайте я покажу конкретные результаты
> наших клиентов из вашей отрасли — это займёт 2 минуты.

ОЦЕНКА ОТВЕТА
Эмпатия:          [████████░░] 8/10
Аргументация:     [███████░░░] 7/10
Работа с возраж.: [████████░░] 8/10
Тон общения:      [█████████░] 9/10
Общий балл: 8/10
```

## Структура

```
sales-simulator/
├── main.py                 # точка входа и интерфейс
├── llm_client.py           # работа с OpenRouter
├── objection_trainer.py    # логика тренировки
├── config.py               # настройки и база возражений
├── requirements.txt
├── .env                    # ключи (не коммитить)
└── README.md
```

Коротко про модули.

`config.py` — настройки и данные. Типы клиентов, пул возражений.

`llm_client.py` — всё, что связано с LLM. Оценка ответа, генерация советов, статистика использования, fallback-методы.

`objection_trainer.py` — сессия тренировки. Выдача возражений, сохранение ответов, подсчёт прогресса.

## Как расширять

Добавить новый тип клиента просто. В `config.py`:

```python
CLIENT_TYPES = {
    'indecisive': {
        'name': 'Нерешительный',
        'description': 'Долго думает, боится ошибиться'
    }
}

OBJECTIONS_POOL = {
    'indecisive': [
        "Мне нужно подумать",
        "Я не уверен, что это подходит",
        "А если не получится?",
    ]
}
```

Потом добавить fallback-советы в `llm_client.py` и пункт в меню `main.py`.

Новые возражения — просто дописать в `OBJECTIONS_POOL`.

## Что стоит знать

Модели с полем `reasoning` (например stepfun) иногда возвращают рассуждения вместо готового ответа. В коде есть очистка, но при смене модели может понадобиться правка промпта.

Fallback-оценки генерируются с учётом содержания ответа, но всё же случайны — это не замена реальной оценке.

История между сессиями не сохраняется.
